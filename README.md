## Features

- [ ] Record audio from the microphone
- [ ] Transcribe audio to text (English, French, Arabic)
- [ ] Dictation mode: hold a key, speak, text appears at the cursor
- [ ] Meeting mode: record a meeting and save a written transcript

## Privacy

All speech recognition runs locally on your computer. No audio or text is sent to the internet.

## Requirements

- Windows 10/11
- Python 3.12

## Setup

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
